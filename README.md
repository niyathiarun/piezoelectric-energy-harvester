# ⚡ Piezoelectric Energy Harvester for Low-Power Applications

## 📌 Overview

This project demonstrates the design and implementation of a piezoelectric energy harvesting system that converts mechanical vibrations into usable electrical energy. The system captures ambient mechanical energy and converts it into electrical energy using the principle of the Piezoelectric Effect, making it suitable for low-power and self-sustaining electronic applications.

---

## 🎯 Objectives

* To design a system that converts mechanical vibrations into electrical energy
* To efficiently rectify and store the generated energy
* To analyze output performance for practical low-power applications

---

## 🧠 Working Principle

The system operates based on the Piezoelectric Effect, where certain materials generate an electric charge when subjected to mechanical stress.

### 🔄 Process Flow:

1. Mechanical vibration is applied to the piezoelectric sensor
2. The sensor generates an AC voltage
3. The AC signal is passed through a rectifier circuit
4. The output is filtered and stored using capacitors
5. The stored energy can be used to power low-power devices
